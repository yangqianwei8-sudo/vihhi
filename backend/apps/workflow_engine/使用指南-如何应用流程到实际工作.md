# 流程应用到实际工作 - 使用指南

## 📋 快速开始

流程创建完成后，需要3个步骤即可应用到实际业务：

1. **确保流程已启用** - 流程状态必须为"启用"（active）
2. **记录流程代码** - 记住流程的代码（code），这是连接业务的关键
3. **在业务代码中调用** - 使用 `ApprovalEngine.start_approval()` 启动审批

---

## 🚀 第一步：确保流程已启用

### 在流程创建页面：
1. 创建流程后，点击 **"启用并保存"** 按钮
2. 或者将流程状态改为 **"启用"** 后保存

### 检查流程状态：
- ✅ **启用（active）** - 可以使用
- ⚠️ **草稿（draft）** - 未完成配置，不能使用
- ❌ **停用（inactive）** - 已暂停，不能使用

**重要**：只有状态为"启用"的流程才能启动审批！

---

## 🔑 第二步：记录流程代码

流程代码是连接业务对象和审批流程的唯一标识。

### 查看流程代码：
1. 在流程列表页面，可以看到每个流程的代码
2. 在流程详情页面，代码显示在基本信息中
3. 代码格式示例：`document_approval`、`contract_approval`、`wf_20241201120000_1234`

### 常见流程代码命名建议：
- `document_approval` - 发文审批流程
- `contract_approval` - 合同审批流程
- `customer_approval` - 客户审批流程
- `project_approval` - 项目审批流程
- `purchase_approval` - 采购审批流程

---

## 💻 第三步：在业务代码中调用

### 方法一：最简单的使用方式（推荐）

```python
from backend.apps.workflow_engine.services import ApprovalEngine
from backend.apps.workflow_engine.models import WorkflowTemplate

# 1. 获取流程模板（通过流程代码）
workflow = WorkflowTemplate.objects.get(
    code='document_approval',  # 你的流程代码
    status='active'  # 必须是启用状态
)

# 2. 启动审批流程
instance = ApprovalEngine.start_approval(
    workflow=workflow,
    content_object=your_business_object,  # 你的业务对象（如发文、合同等）
    applicant=request.user,  # 申请人
    comment='请审批此业务'  # 申请说明
)

# 3. 完成！审批流程已启动
print(f"审批实例编号：{instance.instance_number}")
```

### 方法二：封装成便捷函数（推荐用于生产环境）

```python
# 在 utils.py 或 services.py 中创建通用函数
from backend.apps.workflow_engine.services import ApprovalEngine
from backend.apps.workflow_engine.models import WorkflowTemplate
from django.contrib.contenttypes.models import ContentType
from backend.apps.workflow_engine.models import ApprovalInstance

def start_business_approval(business_object, workflow_code, applicant, comment=''):
    """
    启动业务审批流程（通用函数）
    
    参数：
        business_object: 业务对象（如 OutgoingDocument、Contract等）
        workflow_code: 流程代码（如 'document_approval'）
        applicant: 申请人（User对象）
        comment: 申请说明
    
    返回：
        ApprovalInstance: 审批实例对象
    """
    # 1. 检查是否已有审批实例
    content_type = ContentType.objects.get_for_model(business_object)
    existing = ApprovalInstance.objects.filter(
        content_type=content_type,
        object_id=business_object.id,
        status__in=['pending', 'approved']
    ).first()
    
    if existing:
        raise ValueError(f'该业务对象已有审批流程：{existing.instance_number}')
    
    # 2. 获取流程模板
    try:
        workflow = WorkflowTemplate.objects.get(
            code=workflow_code,
            status='active'
        )
    except WorkflowTemplate.DoesNotExist:
        raise ValueError(f'未找到启用的审批流程（代码：{workflow_code}）')
    
    # 3. 启动审批
    instance = ApprovalEngine.start_approval(
        workflow=workflow,
        content_object=business_object,
        applicant=applicant,
        comment=comment
    )
    
    return instance

# 使用示例：
instance = start_business_approval(
    business_object=document,  # 你的业务对象
    workflow_code='document_approval',  # 流程代码
    applicant=request.user,
    comment='请审批此发文'
)
```

## 📝 实际应用示例

### 示例1：发文提交时启动审批

```python
# 在 views.py 中
from django.contrib.auth.decorators import login_required
from django.shortcuts import redirect, get_object_or_404
from django.contrib import messages
from backend.apps.workflow_engine.services import ApprovalEngine
from backend.apps.workflow_engine.models import WorkflowTemplate
from backend.apps.delivery_customer.models import OutgoingDocument

@login_required
def submit_document_for_approval(request, document_id):
    """提交发文审批"""
    document = get_object_or_404(OutgoingDocument, id=document_id)
    
    # 检查是否已有审批
    from django.contrib.contenttypes.models import ContentType
    from backend.apps.workflow_engine.models import ApprovalInstance
    
    content_type = ContentType.objects.get_for_model(OutgoingDocument)
    existing = ApprovalInstance.objects.filter(
        content_type=content_type,
        object_id=document.id,
        status__in=['pending', 'approved']
    ).first()
    
    if existing:
        messages.warning(request, '该发文已有审批流程')
        return redirect('delivery_pages:outgoing_document_detail', document_id=document_id)
    
    # 获取流程模板
    try:
        workflow = WorkflowTemplate.objects.get(
            code='document_approval',  # 你的流程代码
            status='active'
        )
    except WorkflowTemplate.DoesNotExist:
        messages.error(request, '未找到启用的发文审批流程')
        return redirect('delivery_pages:outgoing_document_detail', document_id=document_id)
    
    # 启动审批
    try:
        instance = ApprovalEngine.start_approval(
            workflow=workflow,
            content_object=document,
            applicant=request.user,
            comment=f'提交发文审批：{document.title}'
        )
        
        # 更新业务对象状态
        document.status = 'reviewing'  # 审核中
        document.save()
        
        messages.success(request, f'审批流程已启动，实例编号：{instance.instance_number}')
        return redirect('workflow_engine:approval_detail', instance_id=instance.id)
        
    except Exception as e:
        messages.error(request, f'启动审批流程失败：{str(e)}')
        return redirect('delivery_pages:outgoing_document_detail', document_id=document_id)
```

### 示例2：在业务对象模型中添加便捷方法

```python
# 在 models.py 中，为业务对象添加方法
from django.contrib.contenttypes.fields import GenericRelation

class OutgoingDocument(models.Model):
    # ... 现有字段 ...
    
    # 添加通用关系（用于反向查询审批实例）
    approval_instances = GenericRelation(
        'workflow_engine.ApprovalInstance',
        content_type_field='content_type',
        object_id_field='object_id',
        related_query_name='outgoing_document'
    )
    
    def get_current_approval_instance(self):
        """获取当前审批实例"""
        return self.approval_instances.filter(
            status__in=['pending', 'approved']
        ).order_by('-created_time').first()
    
    def start_approval(self, workflow_code='document_approval', applicant=None, comment=''):
        """启动审批流程"""
        from backend.apps.workflow_engine.models import WorkflowTemplate
        from backend.apps.workflow_engine.services import ApprovalEngine
        
        # 检查是否已有审批
        if self.get_current_approval_instance():
            raise ValueError('该发文已有审批流程')
        
        # 获取流程模板
        try:
            workflow = WorkflowTemplate.objects.get(code=workflow_code, status='active')
        except WorkflowTemplate.DoesNotExist:
            raise ValueError(f'未找到启用的审批流程（代码：{workflow_code}）')
        
        # 启动审批
        instance = ApprovalEngine.start_approval(
            workflow=workflow,
            content_object=self,
            applicant=applicant,
            comment=comment
        )
        
        # 更新状态
        self.status = 'reviewing'
        self.save(update_fields=['status'])
        
        return instance

# 使用示例：
document = OutgoingDocument.objects.get(id=123)
instance = document.start_approval(
    workflow_code='document_approval',
    applicant=request.user,
    comment='请审批此发文'
)
```

## 🔍 查询审批状态

### 从业务对象查询审批实例

```python
from django.contrib.contenttypes.models import ContentType
from backend.apps.workflow_engine.models import ApprovalInstance

def get_approval_instance(business_object):
    """获取业务对象的审批实例"""
    content_type = ContentType.objects.get_for_model(business_object)
    return ApprovalInstance.objects.filter(
        content_type=content_type,
        object_id=business_object.id
    ).order_by('-created_time').first()

# 使用
document = OutgoingDocument.objects.get(id=123)
instance = get_approval_instance(document)

if instance:
    print(f"审批状态：{instance.get_status_display()}")
    print(f"当前节点：{instance.current_node.name if instance.current_node else '无'}")
    print(f"实例编号：{instance.instance_number}")
```

## ⚠️ 注意事项

### 1. 流程代码必须唯一
- 每个业务类型应该有一个唯一的流程代码
- 建议使用有意义的代码名称，如 `document_approval`

### 2. 流程状态必须为"启用"
- 只有 `status='active'` 的流程才能启动审批
- 草稿和停用的流程无法使用

### 3. 避免重复启动
- 启动前检查是否已有审批实例
- 避免同一业务对象启动多个审批流程

### 4. 异常处理
- 启动审批可能失败（如找不到审批人）
- 需要捕获异常并给用户友好的提示

### 5. 状态同步
- 审批完成后，需要同步更新业务对象状态
- 可以通过信号或回调函数实现

## 💡 常见问题

### Q: 如何知道流程代码是什么？
A: 在流程列表或详情页面可以看到流程代码，或者在创建流程时系统会自动生成。

### Q: 启动审批后，审批人如何看到待审批任务？
A: 审批人可以在"我的审批"页面看到待审批的任务。

### Q: 如何查询业务对象的审批状态？
A: 使用 `get_approval_instance()` 函数或通过 `approval_instances` 关系查询。

### Q: 审批完成后，业务对象状态会自动更新吗？
A: 需要手动同步，可以在审批完成的信号中更新业务对象状态。
