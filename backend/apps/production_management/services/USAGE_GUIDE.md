# CAD图纸优化咨询使用指南

## 快速开始

### 1. 准备CAD文件

**推荐格式：DXF**
- DXF文件可以直接上传，系统会自动解析
- 如果只有DWG文件，需要先转换为DXF

**转换方法：**
- 使用ODA File Converter（Windows本地）
- 使用AutoCAD另存为DXF
- 使用在线转换工具

### 2. 上传文件

1. 访问AI顾问页面：`/production/ai-advisor/`
2. 填写问题描述：
   - 优化前做法
   - 约束条件
   - 服务类型和专业
3. 上传CAD文件（DXF格式）或图片
4. 点击"提交问题并获取优化建议"

### 3. 查看结果

系统会返回：
- **优化方案**：多个可行方案，包含节省金额和风险等级
- **相似案例**：内部案例库中的相似优化案例
- **分析报告**：详细的技术分析
- **风险评估**：潜在风险和应对措施

## 文件格式说明

### DXF文件（推荐）
- ✅ 直接支持，自动解析
- ✅ 提取图层、实体、尺寸、材料等参数
- ✅ 识别结构元素（梁、柱、板等）
- ✅ 最精确的参数提取

### DWG文件
- ⚠️ 需要先转换为DXF
- 转换工具：ODA File Converter、AutoCAD等
- 转换后按DXF文件处理

### 图片文件（JPG/PNG）
- ✅ 支持Vision API识别
- ⚠️ 参数提取精度较低
- 适合快速预览和初步分析

### PDF文件
- ✅ 转换为图片后识别
- ⚠️ 参数提取精度较低
- 适合文档类图纸

## 最佳实践

### 1. 文件准备
- **优先使用DXF格式**：参数提取最准确
- **确保图纸完整**：包含尺寸标注、材料说明等
- **文件大小**：建议不超过50MB

### 2. 问题描述
- **详细描述**：说明当前做法、存在问题、优化目标
- **约束条件**：预算、时间、规范要求等
- **专业选择**：选择正确的服务类型和专业

### 3. 结果使用
- **多方案对比**：查看所有方案，选择最适合的
- **风险评估**：关注高风险项，制定应对措施
- **参考案例**：查看相似案例，了解实际效果

## 常见问题

### Q: DWG文件如何转换？
**A:** 
1. 使用ODA File Converter（Windows）
2. 使用AutoCAD另存为DXF
3. 使用在线转换工具

### Q: 为什么DXF比图片好？
**A:** 
- DXF包含精确的几何数据
- 可以提取准确的尺寸、材料参数
- 图片只能通过OCR识别，精度较低

### Q: 文件太大怎么办？
**A:** 
- 限制：单个文件不超过50MB
- 建议：压缩文件或分批处理
- 大文件可能需要较长时间

### Q: 解析失败怎么办？
**A:** 
- 检查文件格式是否正确
- 确认文件未损坏
- 尝试转换为其他格式

## 批量处理

### Windows批量转换脚本

使用 `batch_convert_dwg_to_dxf.bat`：
1. 将脚本放在包含DWG文件的文件夹
2. 双击运行
3. 自动转换所有DWG文件为DXF

### 命令行转换

```cmd
# 单个文件转换
DWGConvert.exe input.dwg output.dxf

# 批量转换（使用脚本）
batch_convert_dwg_to_dxf.bat
```
