{% extends "shared/base.html" %} {% comment %} 列表页基础模板 (List Page Base Template) 功能说明： - 提供统一的列表页面布局框架，包含完整的列表页功能 - 支持筛选、搜索、分页、批量操作、列设置等高级功能 - 包含加载状态、错误提示、骨架屏等用户体验优化 主要功能模块： 1. 页面头部：标题、操作按钮（新增等） 2. 统计卡片：可选的数据统计展示 3. 标签页切换：支持多标签页展示 4. 筛选区域：可折叠的筛选条件表单 5. 表格工具栏：打印、列设置等工具按钮 6. 批量操作栏：选中项批量操作（导出、删除等） 7. 数据表格：支持复选框、自定义列显示 8. 分页组件：数据分页导航 重要规定： - 分页设置：所有使用此模板的列表页必须固定为每页显示10条数据 - 在视图函数中必须设置：per_page = 10 - 示例代码： per_page = 10 paginator = Paginator(queryset, per_page) page_obj = paginator.get_page(page_number) 可覆盖的模板块： - list_page_title: 页面标题 - list_page_filter_fields: 筛选字段 - list_page_table_search: 表格搜索框（可选） - list_page_table_stats: 表格统计信息（可选） - list_page_table_toolbar: 表格工具栏 - list_page_table_toolbar_left: 表格工具栏左侧 - list_page_table_toolbar_right: 表格工具栏右侧 - list_page_table_headers: 表格列头 - list_page_table_row_content: 表格行内容（数据列） - list_page_table_actions_cell: 操作列单元格（可选，默认显示查看/编辑/删除） - list_page_table_checkbox_header: 复选框列头（可选） - list_page_table_checkbox_cell: 复选框单元格（可选） - list_page_custom_js: 自定义JavaScript代码 JavaScript功能： - 筛选表单自动提交（防抖） - 复选框全选/取消全选 - 列设置保存（localStorage） - 批量操作栏显示/隐藏控制 - 键盘快捷键支持（Ctrl+P打印、Ctrl+F搜索） - 表格搜索功能（实时过滤，可选：show_table_search=True） - 表格统计信息（总记录数、显示数，可选：show_table_stats=True） - 表格导出功能（导出为CSV/Excel，可选：show_table_export=True） - 列排序功能（点击表头排序，可选：enable_table_sort=True，需在表头添加class="sortable"） - 行点击功能（点击行高亮，可选：enable_table_row_click=True） {% endcomment %} {% block title %}{{ page_title|default:"列表" }} - 维海科技信息化管理平台{% endblock %} {% load static %} {% block extra_css %} {# 工作区基础样式 #} {% include 'shared/_workspace_resources.html' %} {# 列表页面额外样式 #} {% block list_page_extra_css %}{% endblock %} {% endblock %} {% block content %} {# 工作区布局结构 #}
