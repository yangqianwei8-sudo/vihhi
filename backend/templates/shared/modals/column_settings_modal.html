{% comment %} 自定义表格字段设置模态框模板 (Column Settings Modal Template) 功能说明： - 提供表格列自定义设置的模态框界面 - 支持显示/隐藏列、设置列宽度 - 提供全选、反选、搜索等辅助功能 - 设置保存在localStorage中，按页面路径区分 使用方法： - 在list_page_base.html的modals块中包含此模板 - 通过表格右上角的齿轮按钮（#columnSettingsBtn）触发打开 - JavaScript初始化代码在list_page_base.html中已提供 主要元素： - #columnSettingsModal: 模态框容器 - #columnSettingsList: 列设置列表容器（动态生成） - #saveColumnSettings: 保存设置按钮 - #resetColumnSettings: 重置为默认按钮 - #selectAllColumns: 全选列按钮 - #invertSelection: 反选列按钮 - #columnSearchInput: 列名搜索输入框 JavaScript使用： - openModal('columnSettingsModal') - 打开模态框 - closeModal('columnSettingsModal') - 关闭模态框 {% endcomment %}
自定义表格字段
勾选复选框可显示/隐藏列，未选中的列将被隐藏。调整宽度：点击快捷按钮（窄/中/宽/默认）或输入自定义值（如：100px 或 15%），输入纯数字会自动添加px单位。修改会实时预览，点击"保存设置"后生效。
