{% comment %} 筛选字段设置模态框模板 (Filter Fields Settings Modal Template) 功能说明： - 提供筛选字段自定义设置的模态框界面 - 支持显示/隐藏筛选字段、拖拽排序 - 提供全选、反选、搜索等辅助功能 - 设置保存在localStorage中，按页面路径区分 使用方法： - 在list_page_base.html的modals块中包含此模板 - 通过筛选区域的设置按钮（#settingsFilterFieldsBtn）触发打开 - JavaScript初始化代码在list_page_base.html中已提供 主要元素： - #filterFieldsSettingsModal: 模态框容器 - #filterFieldsList: 筛选字段列表容器（动态生成） - #saveFilterFieldsSettings: 保存设置按钮 - #resetFilterFieldsSettings: 重置为默认按钮 - #selectAllFilterFields: 全选字段按钮 - #invertFilterFieldsSelection: 反选字段按钮 - #filterFieldsSearchInput: 字段名搜索输入框 样式说明： - 使用Bootstrap模态框样式 - 包含自定义的筛选字段设置项样式（.filter-field-settings-item） - 支持拖拽排序（需要额外的拖拽库支持） {% endcomment %}
