# 白盒验收清单（公司隔离）- 交付表

约定：隔离基石为 `request.user.company_id`，`CompanyIsolationGuardMiddleware` 保证业务入口用户 company 不为空。

**隔离表定义**：User、Department、Role、Plan、StrategicGoal、ApprovalInstance（选人/列表）、WorkflowTemplate（列表）、Client/合同/档案等业务表。

### G1）User：无 company 为 null

```bash
cd /path/to/weihai_tech_production_system   # 项目根目录
python manage.py shell -c "

print('User.objects.filter(company__isnull=True).count():', null_count)
assert null_count == 0, 'P0-2 要求：无 company 为 null 的用户'
print('OK: User 公司回填通过')
"
```

```
User.objects.filter(company__isnull=True).count(): 0
OK: User 公司回填通过
```

### G2）Department：按公司过滤

```bash
python manage.py shell -c "
from backend.apps.system_management.models import Department, User
u = User.objects.filter(company_id__isnull=False).first()
if u:
    depts = Department.objects.filter(company_id=u.company_id)
    print('Department count by company_id:', depts.count())
    print('OK: Department filtered by company')
else:
    print('SKIP: no user with company')
"
```

**回归输出**：
```
Department count by company_id: 7
OK: Department filtered by company
```

### G3）Role：按公司或全局
