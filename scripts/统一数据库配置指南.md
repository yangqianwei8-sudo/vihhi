# 多台电脑会话记录同步配置指南

## 目标
确保四台外地电脑的会话记录都存储在同一个云端数据库中，实现数据同步。

## 核心原理

**所有会话记录都存储在云端数据库中，不是存储在本地电脑上。**

只要所有电脑都连接到同一个数据库，数据就会自动同步。

## 配置步骤

### 第一步：确认数据库连接信息

在任意一台电脑上运行：

```bash
cd /home/devbox/project/vihhi/weihai_tech_production_system
python scripts/check_database_sync.py
```

记录下显示的：
- 主机 (Host)
- 端口 (Port)
- 数据库名 (Database)
- 用户名 (User)

### 第二步：在所有电脑上配置相同的数据库连接

#### 方法1：使用环境变量（推荐）

在每台电脑上执行：

```bash
# 设置环境变量（替换为实际的密码）
export DATABASE_URL="postgresql://postgres:zdg7xx28@dbconn.sealosbja.site:38013/postgres"

# 永久保存（添加到 ~/.bashrc 或 ~/.zshrc）
echo 'export DATABASE_URL="postgresql://postgres:zdg7xx28@dbconn.sealosbja.site:38013/postgres"' >> ~/.bashrc
source ~/.bashrc
```

#### 方法2：使用 .env 文件

在项目根目录创建 `.env` 文件：

```bash
cd /home/devbox/project/vihhi/weihai_tech_production_system
cat > .env << EOF
DATABASE_URL=postgresql://postgres:zdg7xx28@dbconn.sealosbja.site:38013/postgres
EOF
```

确保 `.env` 文件被 `.gitignore` 忽略（不提交到代码库）。

#### 方法3：修改 settings.py（仅用于开发环境）

编辑 `backend/config/settings.py`，确保 `DEVELOPMENT_DATABASE_URL` 指向正确的数据库。

### 第三步：验证配置

在每台电脑上运行验证脚本：

```bash
python scripts/check_database_sync.py
```

**确保所有电脑显示的信息完全一致：**
- ✅ 主机 (Host) 必须相同
- ✅ 端口 (Port) 必须相同
- ✅ 数据库名 (Database) 必须相同
- ✅ 用户名 (User) 必须相同

### 第四步：测试同步

1. **在电脑A上创建测试会话**
   - 使用系统创建一条Agent对话

2. **在电脑B、C、D上验证**
   ```bash
   python scripts/sync_verification.py
   ```
   - 应该能看到相同的会话记录数
   - 应该能看到电脑A创建的会话

3. **如果数据不一致**
   - 检查数据库连接配置
   - 确认连接的是同一个数据库
   - 等待几秒后重试（可能有延迟）

## 同步验证脚本

### 检查数据库连接配置

```bash
python scripts/check_database_sync.py
```

显示当前数据库连接信息，帮助确认配置是否正确。

### 验证同步状态

```bash
python scripts/sync_verification.py
```

显示：
- 当前会话和消息统计
- 按用户和日期统计
- 最新会话信息
- 数据库唯一标识（用于对比）

**在每台电脑上运行此脚本，对比结果：**
- 如果"数据库唯一标识"相同 → 连接的是同一个数据库 ✅
- 如果"总会话数"和"总消息数"相同 → 数据已同步 ✅

## 常见问题

### Q: 如何确认所有电脑连接的是同一个数据库？

A: 运行 `check_database_sync.py`，对比显示的"主机+端口+数据库"信息，必须完全一致。

### Q: 为什么数据不同步？

A: 可能的原因：
1. 连接了不同的数据库实例
2. 数据库连接配置不一致
3. 数据还在同步中（等待几秒）

**解决方法：**
- 检查每台电脑的 `DATABASE_URL` 环境变量
- 确保所有电脑使用相同的连接字符串
- 重新运行验证脚本

### Q: 会话记录会丢失吗？

A: 不会。会话记录存储在云端数据库中，只要数据库正常，数据就不会丢失。即使电脑损坏，数据仍然在云端。

### Q: 如何备份会话记录？

A: 使用备份脚本：

```bash
python scripts/backup_agent_conversations.py
```

备份文件保存在 `backups/agent_conversations/` 目录。

## 配置检查清单

在每台电脑上完成以下检查：

- [ ] 运行 `check_database_sync.py` 显示正确的数据库信息
- [ ] 运行 `sync_verification.py` 显示相同的数据库唯一标识
- [ ] 在一台电脑创建测试会话，其他电脑能看到
- [ ] 所有电脑的会话记录数一致

## 快速配置命令

在一台电脑上配置好后，可以生成配置脚本供其他电脑使用：

```bash
# 生成配置脚本
cat > setup_database_sync.sh << 'EOF'
#!/bin/bash
export DATABASE_URL="postgresql://postgres:zdg7xx28@dbconn.sealosbja.site:38013/postgres"
echo 'export DATABASE_URL="postgresql://postgres:zdg7xx28@dbconn.sealosbja.site:38013/postgres"' >> ~/.bashrc
source ~/.bashrc
echo "✅ 数据库配置完成"
python scripts/check_database_sync.py
EOF

chmod +x setup_database_sync.sh
```

然后在其他电脑上运行这个脚本即可。
