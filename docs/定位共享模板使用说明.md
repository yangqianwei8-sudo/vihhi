# 定位共享模板使用说明

## 概述

系统提供了两个独立的定位共享模板，分别用于不同的使用场景：

1. **静态定位模板** (`static_location_snippet.html`) - 一次性获取位置
2. **动态定位模板** (`dynamic_location_snippet.html`) - 持续跟踪位置变化

两个模板都基于高德地图API实现，提供GPS定位和逆地理编码功能。

## 模板对比

| 特性 | 静态定位模板 | 动态定位模板 |
|------|------------|------------|
| **定位方式** | `getCurrentPosition()` - 一次性获取 | `watchPosition()` - 持续跟踪 |
| **位置更新** | 手动触发，获取一次 | 自动持续更新 |
| **适用场景** | 表单提交、打卡签到 | 实时跟踪、轨迹记录 |
| **按钮功能** | 获取位置 / 重新定位 | 开始跟踪 / 停止跟踪 |
| **UI样式** | 绿色成功卡片 | 黄色跟踪卡片 |
| **性能影响** | 低（一次性） | 较高（持续更新） |
| **电池消耗** | 低 | 较高 |

## 静态定位模板

### 功能特性

- ✅ GPS静态定位（一次性获取）
- ✅ IP定位备选方案
- ✅ 自动地址解析
- ✅ 编辑时回填
- ✅ 适合表单场景

### 文件位置

- **模板文件**: `backend/templates/shared/static_location_snippet.html`
- **JavaScript函数**: `initStaticLocation()`
- **全局对象**: `window.staticLocations[prefix]`

### 使用方法

#### 基本使用

```django
{% include "shared/static_location_snippet.html" with 
    prefix="visit" 
    label="拜访位置"
    auto_locate=True
%}
```

#### 完整配置

```django
{% include "shared/static_location_snippet.html" with 
    prefix="delivery" 
    latitude_field_id="deliveryLatitude"
    longitude_field_id="deliveryLongitude"
    address_field_id="deliveryAddress"
    label="送达位置"
    auto_locate=False
    required=True
    regeocode_api_url="/api/customer/regeocode/"
    ip_location_api_url="/api/customer/ip-location/"
%}
```

### 参数说明

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `prefix` | string | **必需** | ID前缀 |
| `latitude_field_id` | string | `{prefix}Latitude` | 纬度字段ID |
| `longitude_field_id` | string | `{prefix}Longitude` | 经度字段ID |
| `address_field_id` | string | `{prefix}LocationAddress` | 地址字段ID |
| `label` | string | `"位置定位"` | 标签文本 |
| `auto_locate` | boolean | `False` | 是否自动定位 |
| `required` | boolean | `False` | 是否必填 |
| `regeocode_api_url` | string | `"/api/customer/regeocode/"` | 逆地理编码API |
| `ip_location_api_url` | string | `"/api/customer/ip-location/"` | IP定位API |

### 使用场景

- ✅ 客户拜访打卡
- ✅ 交付签收定位
- ✅ 表单提交时记录位置
- ✅ 一次性位置记录

### JavaScript API

```javascript
// 获取定位器实例
const location = window.staticLocations.visit;

// 手动触发GPS定位
location.getGPSLocation(true);

// 手动触发IP定位
location.getIPLocation();

// 检查定位状态
if (location.locationObtained()) {
    console.log('已获取位置');
}

// 更新位置显示
location.updateLocationDisplay(lat, lon, address);
```

## 动态定位模板

### 功能特性

- ✅ GPS动态跟踪（持续更新）
- ✅ 自动地址解析（节流控制）
- ✅ 启动/停止跟踪
- ✅ 最后更新时间显示
- ✅ 适合实时跟踪场景

### 文件位置

- **模板文件**: `backend/templates/shared/dynamic_location_snippet.html`
- **JavaScript函数**: `initDynamicLocation()`
- **全局对象**: `window.dynamicLocations[prefix]`

### 使用方法

#### 基本使用

```django
{% include "shared/dynamic_location_snippet.html" with 
    prefix="tracking" 
    label="位置跟踪"
    watch_interval=5000
    auto_start=True
%}
```

#### 完整配置

```django
{% include "shared/dynamic_location_snippet.html" with 
    prefix="nav" 
    latitude_field_id="navLatitude"
    longitude_field_id="navLongitude"
    address_field_id="navAddress"
    label="导航位置"
    watch_interval=3000
    auto_start=False
    required=False
    regeocode_api_url="/api/customer/regeocode/"
%}
```

### 参数说明

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `prefix` | string | **必需** | ID前缀 |
| `latitude_field_id` | string | `{prefix}Latitude` | 纬度字段ID |
| `longitude_field_id` | string | `{prefix}Longitude` | 经度字段ID |
| `address_field_id` | string | `{prefix}LocationAddress` | 地址字段ID |
| `label` | string | `"位置跟踪"` | 标签文本 |
| `watch_interval` | number | `5000` | 更新间隔（毫秒） |
| `auto_start` | boolean | `False` | 是否自动启动 |
| `required` | boolean | `False` | 是否必填 |
| `regeocode_api_url` | string | `"/api/customer/regeocode/"` | 逆地理编码API |

### 使用场景

- ✅ 实时位置跟踪
- ✅ 移动轨迹记录
- ✅ 导航应用
- ✅ 需要持续更新位置的场景

### JavaScript API

```javascript
// 获取定位器实例
const location = window.dynamicLocations.tracking;

// 启动跟踪
location.startWatchPosition(true);

// 停止跟踪
location.stopWatchPosition();

// 检查是否正在跟踪
if (location.isWatching()) {
    console.log('正在跟踪位置');
}

// 获取最后更新时间
const lastUpdate = location.getLastUpdateTime();
console.log('最后更新:', lastUpdate);
```

## 使用示例

### 示例1：客户拜访表单（静态定位）

```django
<form method="post">
    {% csrf_token %}
    
    <h3>客户拜访信息</h3>
    
    <!-- 其他表单字段 -->
    
    <!-- 静态定位 -->
    {% include "shared/static_location_snippet.html" with 
        prefix="visit" 
        label="拜访位置"
        auto_locate=True
        required=True
    %}
    
    <button type="submit" class="btn btn-primary">提交拜访记录</button>
</form>
```

### 示例2：交付签收（静态定位）

```django
<form method="post">
    {% csrf_token %}
    
    <!-- 静态定位 -->
    {% include "shared/static_location_snippet.html" with 
        prefix="delivery" 
        label="签收位置"
        auto_locate=False
    %}
    
    <button type="submit" class="btn btn-primary">确认签收</button>
</form>

{% block extra_js %}
<script>
document.addEventListener('DOMContentLoaded', function() {
    // 签收时自动获取位置
    const submitBtn = document.querySelector('button[type="submit"]');
    submitBtn.addEventListener('click', function(e) {
        const location = window.staticLocations.delivery;
        if (!location.locationObtained()) {
            e.preventDefault();
            location.getGPSLocation(true);
            // 等待定位完成后提交
            setTimeout(() => {
                if (location.locationObtained()) {
                    submitBtn.closest('form').submit();
                }
            }, 3000);
        }
    });
});
</script>
{% endblock %}
```

### 示例3：实时位置跟踪（动态定位）

```django
<div class="card">
    <div class="card-header">
        <h5>实时位置跟踪</h5>
    </div>
    <div class="card-body">
        <!-- 动态定位 -->
        {% include "shared/dynamic_location_snippet.html" with 
            prefix="tracking" 
            label="当前位置"
            watch_interval=5000
            auto_start=False
        %}
    </div>
</div>

{% block extra_js %}
<script>
document.addEventListener('DOMContentLoaded', function() {
    // 页面加载完成后自动启动跟踪
    setTimeout(() => {
        const location = window.dynamicLocations.tracking;
        location.startWatchPosition(true);
    }, 1000);
    
    // 页面卸载时停止跟踪
    window.addEventListener('beforeunload', function() {
        const location = window.dynamicLocations.tracking;
        if (location.isWatching()) {
            location.stopWatchPosition();
        }
    });
});
</script>
{% endblock %}
```

### 示例4：移动轨迹记录（动态定位）

```django
<form method="post" id="trackForm">
    {% csrf_token %}
    
    <!-- 动态定位 -->
    {% include "shared/dynamic_location_snippet.html" with 
        prefix="route" 
        label="移动轨迹"
        watch_interval=3000
        auto_start=False
    %}
    
    <!-- 轨迹记录列表 -->
    <div id="routePoints" class="mt-3">
        <h6>轨迹点记录</h6>
        <ul id="routePointsList" class="list-group"></ul>
    </div>
    
    <button type="button" class="btn btn-primary" id="startTracking">开始记录</button>
    <button type="button" class="btn btn-secondary" id="stopTracking" style="display:none;">停止记录</button>
    <button type="submit" class="btn btn-success" id="saveRoute" style="display:none;">保存轨迹</button>
</form>

{% block extra_js %}
<script>
document.addEventListener('DOMContentLoaded', function() {
    const location = window.dynamicLocations.route;
    const routePoints = [];
    
    // 开始记录
    document.getElementById('startTracking').addEventListener('click', function() {
        location.startWatchPosition(true);
        this.style.display = 'none';
        document.getElementById('stopTracking').style.display = 'inline-block';
        
        // 记录位置变化
        const originalUpdate = location.updateLocationDisplay;
        location.updateLocationDisplay = function(lat, lon, address) {
            originalUpdate.call(location, lat, lon, address);
            // 记录轨迹点
            routePoints.push({
                latitude: lat,
                longitude: lon,
                address: address,
                timestamp: new Date().toISOString()
            });
            // 更新显示
            updateRoutePointsList();
        };
    });
    
    // 停止记录
    document.getElementById('stopTracking').addEventListener('click', function() {
        location.stopWatchPosition();
        this.style.display = 'none';
        document.getElementById('saveRoute').style.display = 'inline-block';
    });
    
    // 更新轨迹点列表
    function updateRoutePointsList() {
        const list = document.getElementById('routePointsList');
        list.innerHTML = routePoints.map((point, index) => {
            const time = new Date(point.timestamp).toLocaleTimeString('zh-CN');
            return `<li class="list-group-item">
                <strong>点 ${index + 1}</strong>: ${point.address || '地址解析中...'} 
                <small class="text-muted">(${time})</small>
            </li>`;
        }).join('');
    }
    
    // 保存轨迹
    document.getElementById('saveRoute').addEventListener('click', function() {
        // 将轨迹点添加到隐藏字段或表单数据
        const form = document.getElementById('trackForm');
        const input = document.createElement('input');
        input.type = 'hidden';
        input.name = 'route_points';
        input.value = JSON.stringify(routePoints);
        form.appendChild(input);
        form.submit();
    });
});
</script>
{% endblock %}
```

## 注意事项

### 静态定位模板

1. **一次性获取**：每次点击按钮只获取一次位置
2. **IP定位备选**：GPS失败时自动尝试IP定位
3. **适合表单**：适合在表单提交时记录位置

### 动态定位模板

1. **持续跟踪**：启动后会持续更新位置
2. **节流控制**：地址解析有节流机制，避免频繁调用API
3. **电池消耗**：持续GPS跟踪会消耗较多电量
4. **记得停止**：页面卸载前记得停止跟踪

## 故障排查

### GPS定位失败

1. 检查浏览器是否支持Geolocation API
2. 检查用户是否授权位置权限
3. 检查是否使用HTTPS（某些浏览器要求）
4. 查看浏览器控制台错误信息

### 地址解析失败

1. 检查高德地图API配置
2. 检查API配额
3. 检查网络连接
4. 查看API响应错误信息

### 动态跟踪不更新

1. 检查是否已启动跟踪（`isWatching()`）
2. 检查更新间隔设置是否合理
3. 检查GPS信号强度
4. 查看浏览器控制台日志
