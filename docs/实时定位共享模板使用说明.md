## 概述（已废弃）

此文档已废弃。实时定位共享模板已拆分为两个独立的模板，分别用于不同的使用场景。

## 功能特性

- ✅ **GPS实时定位**：使用浏览器Geolocation API获取精确位置
- ✅ **IP定位备选**：当GPS不可用时，自动尝试IP定位
- ✅ **自动地址解析**：调用高德地图API将坐标转换为详细地址
- ✅ **编辑时回填**：支持编辑时自动回填已有位置信息
- ✅ **统一UI展示**：美观的卡片式位置信息展示
- ✅ **可配置性强**：支持自定义字段ID、标签、API路径等

## 文件位置

- **模板文件**: `backend/templates/shared/realtime_location_snippet.html`
- **后端API服务**: `backend/apps/customer_management/services.py` (AmapAPIService类)
- **API端点**: 
  - 逆地理编码: `/api/customer/regeocode/`
  - IP定位: `/api/customer/ip-location/`

## 使用方法

### 1. 基本使用

在表单页面中引入模板：

```django
{% include "shared/realtime_location_snippet.html" with 
    prefix="visit" 
    label="拜访位置"
    auto_locate=True
%}
```

### 2. 完整配置示例

```django
{% include "shared/realtime_location_snippet.html" with 
    prefix="delivery" 
    latitude_field_id="deliveryLatitude"
    longitude_field_id="deliveryLongitude"
    address_field_id="deliveryAddress"
    label="送达位置"
    show_map_preview=False
    auto_locate=True
    required=True
    regeocode_api_url="/api/customer/regeocode/"
    ip_location_api_url="/api/customer/ip-location/"
%}
```

### 3. JavaScript初始化（可选）

如果`auto_locate=False`，可以手动初始化：

```django
{% block extra_js %}
<script>
document.addEventListener('DOMContentLoaded', function() {
    initRealtimeLocation({
        prefix: 'visit',
        latitudeFieldId: 'hiddenLatitude',
        longitudeFieldId: 'hiddenLongitude',
        addressFieldId: 'hiddenLocationAddress',
        regeocodeApiUrl: '/api/customer/regeocode/',
        ipLocationApiUrl: '/api/customer/ip-location/',
        autoLocate: false,
        enableLogging: false
    });
});
</script>
{% endblock %}
```

## 参数说明

### 必需参数

- **prefix** (string): ID前缀，用于区分同一页面中的多个定位器实例

### 可选参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `latitude_field_id` | string | `{prefix}Latitude` | 纬度隐藏字段ID |
| `latitude_field_name` | string | 使用`latitude_field_id` | 纬度隐藏字段name属性 |
| `longitude_field_id` | string | `{prefix}Longitude` | 经度隐藏字段ID |
| `longitude_field_name` | string | 使用`longitude_field_id` | 经度隐藏字段name属性 |
| `address_field_id` | string | `{prefix}LocationAddress` | 地址隐藏字段ID |
| `address_field_name` | string | 使用`address_field_id` | 地址隐藏字段name属性 |
| `label` | string | `"位置定位"` | 定位功能标签 |
| `show_map_preview` | boolean | `False` | 是否显示地图预览（预留功能） |
| `auto_locate` | boolean | `False` | 是否自动定位 |
| `required` | boolean | `False` | 是否必填 |
| `regeocode_api_url` | string | `"/api/customer/regeocode/"` | 逆地理编码API URL |
| `ip_location_api_url` | string | `"/api/customer/ip-location/"` | IP定位API URL |

## 生成的HTML元素

模板会自动生成以下HTML元素：

- **隐藏字段**：
  - `{latitude_field_id}`: 存储纬度值
  - `{longitude_field_id}`: 存储经度值
  - `{address_field_id}`: 存储地址字符串

- **显示元素**：
  - `{prefix}LocationButton`: 定位按钮
  - `{prefix}LocationStatus`: 定位状态显示
  - `{prefix}LocationDisplay`: 位置信息显示容器
  - `{prefix}LocationAddress`: 地址显示
  - `{prefix}LocationCoords`: 坐标显示

## JavaScript API

模板提供了全局JavaScript函数和对象，可以在页面中调用：

### 初始化函数

```javascript
initRealtimeLocation(options)
```

初始化实时定位功能。

**参数**:
- `options.prefix` (string, 必需): ID前缀
- `options.latitudeFieldId` (string, 可选): 纬度字段ID
- `options.longitudeFieldId` (string, 可选): 经度字段ID
- `options.addressFieldId` (string, 可选): 地址字段ID
- `options.regeocodeApiUrl` (string, 可选): 逆地理编码API URL
- `options.ipLocationApiUrl` (string, 可选): IP定位API URL
- `options.autoLocate` (boolean, 可选): 是否自动定位
- `options.enableLogging` (boolean, 可选): 是否启用日志

**返回值**: 定位器对象，包含以下方法：
- `getGPSLocation(showStatus)`: 触发GPS定位
- `getIPLocation()`: 触发IP定位
- `updateLocationDisplay(lat, lon, address)`: 更新位置显示

### 全局对象

```javascript
window.realtimeLocations[prefix]
```

存储所有定位器实例，可以通过prefix访问：

```javascript
// 获取定位器实例
const location = window.realtimeLocations.visit;

// 手动触发GPS定位
location.getGPSLocation(true);

// 检查定位状态
if (location.locationObtained()) {
    console.log('已获取位置');
}
```

## 定位流程

1. **用户点击"获取位置"按钮**（或自动触发）
2. **尝试GPS定位**：
   - 检查浏览器是否支持Geolocation API
   - 请求用户位置权限
   - 获取GPS坐标
3. **如果GPS定位失败**：
   - 自动尝试IP定位
   - 获取IP对应的城市级别位置
4. **调用逆地理编码API**：
   - 将坐标发送到高德地图API
   - 获取详细地址信息
5. **更新UI和表单字段**：
   - 显示位置信息卡片
   - 更新隐藏字段值
   - 更新按钮状态

## 后端API要求

### 逆地理编码API

**端点**: `/api/customer/regeocode/`

**请求参数**:
- `latitude` (float): 纬度
- `longitude` (float): 经度

**响应格式**:
```json
{
    "success": true,
    "formatted_address": "北京市朝阳区阜通东大街6号",
    "province": "北京市",
    "city": "北京市",
    "district": "朝阳区",
    "township": "望京街道",
    "adcode": "110105",
    "message": "获取地址成功"
}
```

### IP定位API

**端点**: `/api/customer/ip-location/`

**请求参数**:
- `ip` (string, 可选): IP地址，不传则使用请求IP

**响应格式**:
```json
{
    "success": true,
    "province": "北京市",
    "city": "北京市",
    "adcode": "110000",
    "center_longitude": 116.407526,
    "center_latitude": 39.904030,
    "message": "IP定位成功"
}
```

## 注意事项

1. **浏览器权限**：GPS定位需要用户授权，首次使用时会弹出权限请求
2. **HTTPS要求**：某些浏览器要求HTTPS才能使用Geolocation API
3. **API配置**：确保高德地图API已在后台配置（通过API管理系统或环境变量）
4. **网络连接**：定位和地址解析需要网络连接
5. **精度差异**：GPS定位精度较高（米级），IP定位精度较低（城市级别）

## 故障排查

### GPS定位失败

1. **检查浏览器支持**：
   ```javascript
   if (!navigator.geolocation) {
       console.error('浏览器不支持GPS定位');
   }
   ```

2. **检查权限**：确保用户已授权位置权限

3. **检查HTTPS**：某些浏览器要求HTTPS

4. **查看控制台**：检查是否有JavaScript错误

### 地址解析失败

1. **检查API配置**：
   - 确认高德地图API Key已配置
   - 检查API配额是否充足

2. **检查网络连接**：
   - 确认可以访问高德地图API
   - 检查防火墙设置

3. **查看API响应**：
   - 在浏览器开发者工具中查看Network请求
   - 检查API返回的错误信息

### 位置信息不显示

1. **检查字段ID**：确保字段ID配置正确

2. **检查JavaScript初始化**：确认`initRealtimeLocation`已调用

3. **检查DOM元素**：确认所有必需的DOM元素都存在
