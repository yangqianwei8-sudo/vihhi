# API IP白名单管理使用说明

## 功能概述

API IP白名单管理功能允许您在后台管理系统中维护各个外部系统（如启信宝）的IP白名单，无需修改代码即可添加、删除或更新IP地址。

## 使用场景

- **开发环境切换**：在不同开发环境中，服务器IP地址可能不同，需要在启信宝等外部系统中配置不同的IP白名单
- **多服务器部署**：生产环境可能有多个服务器，每个服务器都需要添加到白名单
- **临时访问**：需要临时添加某个IP地址到白名单

## 功能特点

1. **可视化管理**：在Django后台管理界面中直接管理IP白名单
2. **自动获取服务器IP**：系统会自动显示当前服务器的公网IP，方便复制添加
3. **系统关联**：每个IP白名单记录都关联到具体的外部系统（如启信宝）
4. **状态管理**：支持启用/停用IP白名单，无需删除记录
5. **描述信息**：可以为每个IP添加描述，说明用途（如：开发服务器、生产服务器等）

## 使用方法

### 1. 访问IP白名单管理

1. 登录Django后台管理系统
2. 导航到 **API管理** → **API IP白名单**
3. 点击 **添加API IP白名单** 按钮

### 2. 添加新的IP白名单

1. **选择外部系统**：在下拉框中选择需要配置白名单的外部系统（如：启信宝）
2. **查看当前服务器IP**：在"服务器信息"区域，系统会自动显示当前服务器的公网IP地址
3. **复制IP地址**：点击IP地址区域，复制显示的IP地址
4. **填写IP地址**：将复制的IP地址粘贴到"IP地址"字段
5. **添加描述**（可选）：填写描述信息，如"开发服务器"、"生产服务器"等
6. **设置状态**：选择"启用"状态
7. **保存**：点击"保存"按钮

### 3. 管理现有IP白名单

- **查看列表**：在IP白名单列表页面，可以查看所有已配置的IP地址
- **编辑**：点击记录可以编辑IP地址、描述或状态
- **停用**：将状态改为"停用"可以临时禁用某个IP，无需删除记录
- **删除**：如果不再需要某个IP，可以直接删除记录

### 4. 筛选和搜索

- **按系统筛选**：使用"所属系统"筛选器可以查看特定系统的IP白名单
- **按状态筛选**：使用"状态"筛选器可以查看启用或停用的IP
- **搜索**：可以使用搜索框搜索IP地址、描述或创建人

## 技术实现

### 数据模型

IP白名单数据存储在 `api_ip_whitelist` 表中，包含以下字段：

- `external_system`：关联的外部系统
- `ip_address`：IP地址（IPv4或IPv6）
- `description`：描述信息
- `status`：状态（启用/停用）
- `is_active`：是否激活
- `created_by`：创建人
- `created_time`：创建时间
- `updated_time`：更新时间

### 获取IP白名单

在代码中，可以通过以下方式获取指定系统的IP白名单：

```python
from backend.apps.api_management.models import ApiIpWhitelist

# 获取启信宝系统的所有启用IP白名单
whitelisted_ips = ApiIpWhitelist.get_whitelisted_ips('QIXINBAO')
# 返回：['101.126.54.244', '192.168.1.100', ...]
```

### 获取当前服务器IP

```python
from backend.apps.api_management.models import ApiIpWhitelist

# 获取当前服务器的公网IP
current_ip = ApiIpWhitelist.get_current_server_ip()
# 返回：'101.126.54.244' 或 None（如果获取失败）
```

## 注意事项

1. **唯一性约束**：同一外部系统的同一IP地址只能有一条记录
2. **IP格式验证**：系统会自动验证IP地址格式（支持IPv4和IPv6）
3. **自动获取IP**：系统会尝试多个IP查询服务来获取当前服务器IP，如果都失败，会显示提示信息
4. **权限控制**：只有有权限访问后台管理的用户才能管理IP白名单

## 常见问题

### Q: 如何知道当前服务器的IP地址？

A: 在添加或编辑IP白名单记录时，系统会自动在"服务器信息"区域显示当前服务器的公网IP地址，可以直接复制使用。

### Q: 可以添加多个IP地址吗？

A: 可以。每个IP地址需要单独创建一条记录。同一系统的不同IP地址可以有多条记录。

### Q: 停用和删除有什么区别？

A: 
- **停用**：保留记录，但该IP不会被使用。可以随时重新启用。
- **删除**：永久删除记录，无法恢复。

### Q: 如何批量导入IP地址？

A: 目前不支持批量导入，需要逐个添加。未来可以考虑添加批量导入功能。
