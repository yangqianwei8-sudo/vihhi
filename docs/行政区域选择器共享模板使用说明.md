# 行政区域选择器共享模板使用说明

## 概述

行政区域选择器是一个基于高德地图API的三级联动下拉选择组件，提供省/市/区三级行政区划选择功能。

## 文件位置

- **模板文件**: `backend/templates/shared/district_selector_snippet.html`
- **JavaScript组件**: `backend/static/js/amap-district-selector.js`
- **后端API**: `/api/customer/districts/`

## 功能特性

1. **三级联动**: 省份、城市、区县三级联动选择
2. **自动更新**: 选择后自动更新地址隐藏字段
3. **地址解析**: 支持编辑时自动解析已有地址并回填
4. **多种格式**: 支持名称、编码、或同时存储编码和名称
5. **错误处理**: 完善的错误提示和降级处理
6. **可配置**: 丰富的配置选项，适应不同场景

## 快速开始

### 1. 在表单中引入模板

```django
{% include "shared/district_selector_snippet.html" with 
    prefix="project" 
    province_label="省份" 
    city_label="城市" 
    district_label="区县"
    address_field_id="projectAddressField"
    address_field_name="project_address"
    detail_input_id="addressDetailInput"
    show_detail_input=True
%}
```

### 2. 加载JavaScript并初始化

```django
{% block extra_js %}
{{ block.super }}
<script src="{% static 'js/amap-district-selector.js' %}"></script>
<script>
document.addEventListener('DOMContentLoaded', function() {
    initDistrictSelector({
        prefix: 'project',
        addressFieldId: 'projectAddressField',
        detailInputId: 'addressDetailInput',
        apiBaseUrl: '/api/customer/districts/',
        addressFormat: 'name'  // 'name', 'code', 'both'
    });
});
</script>
{% endblock %}
```

## 参数说明

### 模板参数

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `prefix` | string | 是 | - | ID前缀，用于区分同一页面中的多个选择器实例 |
| `province_label` | string | 否 | "省份" | 省份下拉框标签 |
| `city_label` | string | 否 | "城市" | 城市下拉框标签 |
| `district_label` | string | 否 | "区县" | 区县下拉框标签 |
| `address_field_id` | string | 否 | `{prefix}AddressField` | 地址隐藏字段ID |
| `address_field_name` | string | 否 | 使用`address_field_id` | 地址隐藏字段name属性 |
| `detail_input_id` | string | 否 | `{prefix}AddressDetail` | 详细地址输入框ID |
| `detail_input_name` | string | 否 | 使用`detail_input_id` | 详细地址输入框name属性 |
| `show_detail_input` | boolean | 否 | True | 是否显示详细地址输入框 |
| `required` | boolean | 否 | False | 是否必填 |
| `address_format` | string | 否 | 'name' | 地址格式：'name'（名称）、'code'（编码）、'both'（编码\|名称） |

### JavaScript初始化参数

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `prefix` | string | 是 | - | ID前缀，必须与模板中的prefix一致 |
| `addressFieldId` | string | 否 | `{prefix}AddressField` | 地址隐藏字段ID |
| `detailInputId` | string | 否 | `{prefix}AddressDetail` | 详细地址输入框ID |
| `apiBaseUrl` | string | 否 | '/api/customer/districts/' | API基础URL |
| `autoUpdateAddress` | boolean | 否 | true | 是否自动更新地址字段 |
| `enableLogging` | boolean | 否 | false | 是否启用日志 |
| `addressFormat` | string | 否 | 'name' | 地址格式：'name'、'code'、'both' |

## 地址格式说明

### 1. 名称格式（默认）

```javascript
addressFormat: 'name'
```

保存格式：`北京市 北京市 朝阳区 详细地址`

### 2. 编码格式

```javascript
addressFormat: 'code'
```

保存格式：`110000 110100 110105 详细地址`

### 3. 编码+名称格式

```javascript
addressFormat: 'both'
```

保存格式：`110000|北京市 110100|北京市 110105|朝阳区 详细地址`

## API方法

### 获取选择器实例

```javascript
// 通过全局对象访问
const selector = window.districtSelectors['project'];

// 或通过initDistrictSelector返回值
const selector = initDistrictSelector({ prefix: 'project' });
```

### 常用方法

```javascript
// 获取完整地址
const address = selector.getFullAddress();

// 设置地址（会自动解析并回填）
selector.setAddress('北京市 北京市 朝阳区 某某街道123号');

// 获取编码信息
const codes = selector.getCodes();
// 返回: { provinceCode: '110000', provinceName: '北京市', ... }

// 设置编码（用于编辑场景）
selector.setCodes({
    provinceCode: '110000',
    provinceName: '北京市',
    cityCode: '110100',
    cityName: '北京市',
    districtCode: '110105',
    districtName: '朝阳区'
});

// 重置选择器
selector.reset();
```

## 错误处理

组件内置了完善的错误处理机制：

1. **API不可用**: 显示警告提示，用户可手动输入详细地址
2. **网络错误**: 显示网络错误提示
3. **数据加载失败**: 显示加载失败提示

错误提示会自动显示在选择器下方，用户可以通过关闭按钮关闭提示。

## 注意事项

1. **API依赖**: 需要后端提供 `/api/customer/districts/` API接口
2. **高德地图API Key**: 后端需要配置高德地图API Key（在`.env`文件中）
3. **ID唯一性**: 同一页面中多个选择器必须使用不同的`prefix`
4. **JavaScript加载顺序**: 必须先加载`amap-district-selector.js`，再调用`initDistrictSelector`
5. **编辑场景**: 如果表单有初始值，组件会自动解析并回填到下拉框中

## 后端API要求

后端API需要支持以下查询参数：

- `keywords`: 查询关键词（省份编码、城市编码等）
- `level`: 查询级别（'country', 'province', 'city', 'district'）
- `subdistrict`: 是否返回下级行政区划（0或1）

API响应格式：

```json
{
    "success": true,
    "districts": [
        {
            "adcode": "110000",
            "name": "北京市",
            "level": "province",
            "districts": [...]
        }
    ],
    "message": "获取成功"
}
```

## 故障排查

### 问题1：下拉框没有选项

- 检查后端API是否正常：访问 `/api/customer/districts/?keywords=&level=province`
- 检查浏览器控制台是否有错误
- 检查高德地图API Key是否配置正确

### 问题2：选择省份后城市没有加载

- 检查网络请求是否成功（浏览器开发者工具 -> Network）
- 检查API返回的数据格式是否正确
- 检查`subdistrict`参数是否为1

### 问题3：地址没有自动更新

- 检查`autoUpdateAddress`配置是否为true
- 检查地址隐藏字段ID是否正确
- 检查浏览器控制台是否有JavaScript错误
